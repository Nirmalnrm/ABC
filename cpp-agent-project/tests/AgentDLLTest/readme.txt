Your tasks:

- Compile the C++ source file simple_agent.cpp to a DLL.
  The necessary commands are given in simple_agent.cpp if you use the GNU C Compiler (but you don't have to).

- Test the interaction between agent DLL and host program on the command line by calling:
  host simple_agent.dll
  This will let the host program load the DLL, call it multiple times, and display the exchanged information.
