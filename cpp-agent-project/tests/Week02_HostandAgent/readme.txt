Your tasks:

- Compile the C++ source file stupid_agent.cpp to a DLL.
  The necessary commands are given in stupid_agent.cpp if you use the GNU C Compiler (but you don't have to).

- Test the interaction between agent DLL and host program on the command line by calling:
  host stupid_agent.dll
  or by executing host.exe and drag-and-dropping the DLL using your mouse.
  
- Note that you can drop a second player DLL on the host GUI, or provide the name of a second DLL on the command line

- Make yourself familiar with the API, the barebones agent source file, and start developing your agent!
